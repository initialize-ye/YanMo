研墨 AI · Windows 绿色便携版
========================================

一、启动
1. 将压缩包完整解压到任意文件夹（建议路径不含特殊符号，例如 D:\YanMo）。
2. 双击「启动研墨.cmd」。
3. 浏览器会自动打开 http://localhost:3000。
   如果 3000 端口被占用，程序会自动改用 3001、3002……请以黑色窗口里显示的地址为准。
4. 关闭黑色命令行窗口，即停止服务。

不需要安装 Node.js，运行环境已经放在 runtime 文件夹里。

二、接入 AI
首次使用时，请在页面右上角「设置」里填写：
- 接口地址 Base URL：例如 https://api.deepseek.com
- 模型名称：例如 deepseek-flash
- API Key

支持任何兼容 OpenAI Chat Completions 的接口。
不填 Key 也可以先打开「示例批改」查看完整报告效果。

如果希望所有使用者共用同一个 Key，可以在本目录新建 .env.local，内容示例：
  AI_API_KEY=sk-xxxxxxxx
  AI_BASE_URL=https://api.deepseek.com
  AI_MODEL=deepseek-flash

注意：
- 带 Key 的 .env.local 不要随绿色包一起转发给不信任的人。
- 浏览器「设置」里填写的 Key 只保存在本机浏览器，优先级高于 .env.local。

三、数据保存在哪里
作文与批改报告保存在当前浏览器的 localStorage 中，不会上传到研墨服务器。
换浏览器、清除浏览器数据或更换电脑后会丢失。
重要报告请在「设置 → 数据与隐私」中导出 JSON 备份。

四、常见问题
1. Windows 提示“Windows 已保护你的电脑”
   这是未签名的 node.exe 触发的 SmartScreen 提示。
   点击「更多信息」→「仍要运行」即可。

2. 启动窗口一闪而过
   通常是压缩包没有解压完整，或 runtime\node.exe 被删除。
   请重新解压完整压缩包后再试。

3. 页面打不开
   先看黑色窗口里显示的地址和端口，确认浏览器访问的是同一个地址。
   如果一直停在启动阶段，请把窗口内容截图反馈。

4. 想给同一局域网的同学访问
   可以在 .env.local 中加入：
     HOSTNAME=0.0.0.0
   然后用本机 IP（例如 http://192.168.1.10:3000）访问。
   这需要在 Windows 防火墙中放行，且只建议在可信局域网使用。
   不要把服务直接暴露到公网。

五、目录说明
- 启动研墨.cmd / 启动研墨.ps1：启动器
- runtime\node.exe：内置的 Node.js 运行环境
- server.js / .next：网页程序本体
- .env.local（可选）：服务端 AI 配置
